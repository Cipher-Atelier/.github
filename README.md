# Cipher Atelier community files

Shared entry points and community defaults for Cipher Atelier, an informal research community founded by [Maxim Egorov](https://github.com/cayde-6).

[Cipher Atelier](https://github.com/Cipher-Atelier) · [Research index](https://github.com/Cipher-Atelier/research-index) · [Start contributing](https://github.com/Cipher-Atelier/research-index/blob/main/START_HERE.md)

## Start here

- [Organization profile](profile/README.md): the public introduction, investigations, membership and research support information shown on the organization page.
- [Contribution guide](CONTRIBUTING.md): coordination, evidence, reproducibility, attribution, AI disclosure and source rights.
- [Community code of conduct](CODE_OF_CONDUCT.md): expectations for participation and moderation.
- [Repository style](https://github.com/Cipher-Atelier/research-index/blob/main/docs/REPOSITORY_STYLE.md): the shared presentation and verification standard for research entry points.

Public issues and pull requests do not require organization membership. Follow the profile for private membership applications and founder contact.

## Shared community defaults

GitHub uses supported community files from this public `.github` repository when a repository has no corresponding local override. This includes the root [contribution guide](CONTRIBUTING.md) and [code of conduct](CODE_OF_CONDUCT.md), plus these files in [`.github/`](.github/):

- [Issue templates](.github/ISSUE_TEMPLATE/): forms and chooser links for existing research and new proposals. A repository with a local `.github/ISSUE_TEMPLATE` directory replaces the entire default chooser; defaults are not merged with it.
- [Pull request template](.github/PULL_REQUEST_TEMPLATE.md): prompts for the scope, evidence, checks and rights of a contribution.
- [Funding configuration](.github/FUNDING.yml): the founder's GitHub Sponsors link.

These defaults apply after publication on the default branch. Check the actual contribution interface when provisioning a repository. GitHub documents the supported files and precedence in [default community health files](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file).

The [CODEOWNERS file](.github/CODEOWNERS) applies to this repository only. CODEOWNERS, README files, workflows and licences do not inherit from this repository; each project needs its own applicable files. These community defaults do not grant rights to source images or other third-party material.
